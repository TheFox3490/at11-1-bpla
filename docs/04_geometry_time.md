# 1.4 Безопасная геометрия и время

## Расширение запретных зон

Горизонтальный радиус аппарата 0,10 м, дополнительный запас 0,05 м,
ошибка положения исполнителя 0,06 м, ошибка взаимной привязки 0,02 м:

```
FORBIDDEN_EXPANSION = 0.10 + 0.05 + 0.06 + 0.02 = 0.23 м
```

Запретная зона расширяется на 0,23 м; маршрут, пересекающий расширенный
контур, отвергается. Дополнительно исполнитель проверяет каждый отрезок
маршрута перед вылетом и каждый шаг полёта, а при входе в реальную зону
немедленно прекращает операцию и выполняет аварийную посадку.

## Рабочая операция

| Величина | Значение |
|---|---|
| рабочая область цели | круг R = 0,25 м |
| условный радиус воздействия | 0,04 м |
| ошибка цели (разведка) | ≤ 0,13 м |
| ошибка исполнителя + привязка | 0,06 + 0,02 м |
| требуемое условие | `e_цели + 0.06 + 0.02 + 0.04 ≤ 0.25` |

Для операции отдельно учитываются ошибка цели и радиус воздействия: цель
считается допустимой только если её круг радиусом 0,25 м целиком лежит вне
расширенной запретной зоны (`distance_to_polygon > 0.23`).

## Какие преобразования добавляют ошибку

1. **Изображение → локальная система разведчика**: фокусное расстояние,
   высота, ориентация камеры, наклон (в проекте — надир).
2. **Локальная система разведчика → F**: калибровка по маркерам (подобие),
   ошибка контрольных точек.
3. **F → локальная система исполнителя**: другая точка начала и другой курс;
   взаимная привязка 0,02 м.
4. **Локальная система исполнителя → фактическое положение**: ошибка
   позиционирования 0,06 м.

Каждый переход явно указан, ни одна система не считается совпадающей с F.

## Время

| Ограничение | Значение | Как проверяется |
|---|---|---|
| разведка | ≤ 360 с | `RECON_LIMIT_SECONDS`, таймер прогона |
| обработка между вылетами | ≤ 180 с | фактическое время CV (доли секунды) и отчёт |
| исполнение | ≤ 360 с | `EXEC_LIMIT_SECONDS` + бюджет миссии с резервом |
| срок действия карты | 900 с после последнего кадра | `valid_until`, проверяется перед стартом и на каждом шаге |

Оценка времени маршрута:

```
T = L / v + N × (стабилизация 1 с + операция 2 с + переход 0.5 с) + резерв
резерв = max(20 с, 20 % от оценки)
```

Проверка на реальном прогоне: маршрут 9,32 м, оценка 44 с, резерв 20 с,
итого 64 с при лимите 360 с. При бюджете 60 с планировщик оставляет
подмножество из 5 целей и записывает причину пропуска шестой.

## Поведение при нехватке ресурса

* **Планирование**: если полный маршрут не влезает в бюджет с резервом,
  выбирается подмножество по приоритету (пропускается цель с наибольшим
  номером приоритета), причины пишутся в `skipped` и в миссию.
* **Исполнение**: если бюджет исчерпан в полёте, операция прекращается,
  LED выключается, дрон возвращается на точку старта и садится.
* **Просрочка карты в полёте**: новые операции запрещены, немедленный
  возврат и посадка (сценарий C3).
* **Потеря локализации > 0,3 с**: LED выключается, аварийная посадка на
  месте (навигация ненадёжна).
* **Потеря связи управления**: LED выключается, автономный возврат на точку
  старта и посадка.
