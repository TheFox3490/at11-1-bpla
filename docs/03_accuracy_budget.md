# 1.3 Бюджет погрешностей

Заданы верхние оценки:

| Источник | Ошибка |
|---|---|
| положение цели по разведке | 0,07 м |
| положение исполнителя | 0,06 м |
| взаимная привязка систем | 0,02 м |
| условный радиус воздействия | 0,04 м |

## Консервативная сумма

```
e_sum = 0,07 + 0,06 + 0,02 = 0,15 м
e_sum + r_возд = 0,15 + 0,04 = 0,19 м
R_цели = 0,25 м
запас = 0,25 − 0,19 = 0,06 м (24 % от радиуса)
```

Условие `e_sum + r_возд ≤ R_цели` выполняется с запасом 0,06 м.

## Почему нельзя складывать квадратично без обоснования

Среднеквадратичное суммирование `sqrt(e1² + e2² + …)` даёт меньшую оценку
только если ошибки независимы, симметричны и имеют известные распределения.
В учебной модели этого не доказано: калибровка, привязка и позиционирование
могут иметь общий источник погрешности (например, неточная разметка маркеров
сразу влияет и на привязку, и на положение цели). Поэтому принята
консервативная арифметическая сумма, а не оптимистичная.

## Как это зашито в код

* `MAX_RECON_ERROR = 0.13 м` — предел ошибки разведки, выведенный из бюджета:
  `0.13 + 0.06 + 0.02 + 0.04 = 0.25`.
* Валидатор (`cv/validator.py`) отвергает цель, если
  `position_error_m + 0.06 + 0.02 + 0.04 > 0.25`.
* Ошибка каждой цели теперь не константа: `max(0.07, остаток калибровки +
  разброс повторных наблюдений)`. Если оценка выходит за 0.13 м, цель
  отклоняется с причиной `position_error_out_of_limit` — сомнительная
  координата не используется.
* Калибровка с контрольной точкой хуже 30 мм отвергается целиком
  (`CalibrationError`), требуется повторная разведка.

## Результат на учебном прогоне

| Проверка | Значение |
|---|---|
| худшая контрольная точка (независимая) | 0,07 мм |
| средняя ошибка контрольных точек | 0,04 мм |
| ошибка целей относительно раскладки, средняя | 10,6 мм |
| ошибка целей относительно раскладки, максимальная | 18,3 мм |

То есть фактический запас заметно больше расчётного: 18 мм против
допустимых 70 мм на входе миссии. Запас нужен не «для красоты»: он покрывает
высоту объектов над плоскостью, перспективу и погрешность разметки.

## Если испытания покажут больше

Порядок действий зафиксирован заранее:

1. увеличить запас (снизить допустимую ошибку разведки) и повторить
   калибровку;
2. пометить сомнительные цели как `U` и не выполнять операцию;
3. при систематическом превышении — запретить операцию до устранения
   причины (перекалибровка, другая высота, проверка маркеров).
